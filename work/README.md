# Финансовый дашборд

Веб-дашборд на Google Apps Script для анализа денежных потоков, прибыли и капитала. Проект связан с таблицей Google Sheets и состоит из главной страницы «Дашборд» и трёх дочерних страниц: «Деньги», «Прибыль», «Капитал».

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `template.html`, `gstemplate.gs` | Главная оболочка веб-приложения и роутинг страниц. |
| `dashboard.html`, `gsdashboard.gs` | Главная страница: KPI, динамика, оборачиваемость, ликвидность. |
| `money.html`, `gsmoney.gs` | Денежные потоки, структура расходов, контрагенты и Cash Buffer. |
| `profit.html`, `gsprofit.gs` | Анализ отчёта о прибыли и убытках. |
| `capital.html`, `gscapital.gs` | Снимки капитала, ликвидность и структура баланса. |
| `gscore.gs` | Общие настройки, форматирование и API-утилиты. |

## Источник данных

Скрипт использует именованные диапазоны в привязанной Google-таблице:

| Лист | Именованный диапазон | Ключевые поля |
| --- | --- | --- |
| `Деньги` | `rangecash` | `Дата`, `Сумма`, `Вид операции`, `Счет`, `Контрагент`, `Статья`, `Раздел ОДДС`, `Направление`. |
| `Прибыль` | `rangeprofit` | `Дата`, `Сумма`, `Направление`, `Наименование проекта`, `Вид операции`, `Статья ОПиУ`, `Раздел ОПиУ`. |
| `Капитал` | `rangeequity` | `Дата`, `Раздел 1`, `Раздел 2`, `Раздел 3`, `Раздел 4`, `Сумма`. |

## Период

Начало и конец периода можно задать на любой странице (Дашборд, Деньги, Прибыль, Капитал). Выбранные даты сохраняются в `localStorage` (см. `window.APP_SAVE_PERIOD` / `APP_CLEAR_PERIOD` в `template.html`) и подставляются на все остальные страницы при переходе — независимо от того, где период был изменён.

## Ключевые правила расчёта

- **Текущая ликвидность**: `Краткосрочные обязательства / Оборотные активы` на последнюю доступную дату среза капитала.
- **Cash Buffer**: положительное значение `|чистый денежный поток / среднедневной расход|`. Для расхода используются строки раздела `2. Основная деятельность` с видом операции `Расход`; среднедневной расход — сумма этих расходов, делённая на число календарных дней периода.
- **Оборачиваемость ДЗ и КЗ**: рассчитывается с 1 января года конечной даты периода до последнего снимка капитала; в карточке показываются дни, а в подписи — коэффициент в разах и фактические даты срезов.
- Денежные значения выводятся в **млн руб.**, относительные показатели — в **%**.

## Запуск и публикация

1. Откройте связанный проект в Google Apps Script.
2. Убедитесь, что именованные диапазоны и заголовки столбцов существуют и соответствуют таблице выше.
3. Выполните нужную публичную функцию для проверки данных, например `dashboardGetDashboardData` или `cashGetMoneyData`.
4. Для обновления доступного пользователям веб-приложения создайте новую версию в разделе «Развернуть» / «Управление развертываниями».

Изменение кода само по себе не обновляет уже опубликованную версию веб-приложения.
